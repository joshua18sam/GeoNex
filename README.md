# 🌍 GeoNex
### Edge-AI and IoT Based Road Hazard Detection and Mapping System

GeoNex is a road hazard detection and mapping project designed
to identify potholes and speed breakers using computer vision,
inertial sensing, and GPS-based localization.

The long-term goal is to create a shared road hazard map that
can be continuously updated by participating vehicles.

## 🏆 Achievement
🥇 First Place — Hackathon

## 🎯 Objectives
- Detect potholes and speed breakers.
- Obtain geographic coordinates using GPS.
- Investigate IMU-based road impact detection.
- Explore sensor fusion for improved detection reliability.
- Develop an interactive road hazard map.
- Support crowdsourced road condition reporting.

## 🛠️ Hardware
- Raspberry Pi 5 (8GB)
- USB Camera
- NEO-6M GPS Module
- MPU6050 Accelerometer and Gyroscope
- Arduino for sensor testing

## 💻 Planned Software Stack
- Python
- OpenCV
- YOLO
- Flask
- SQLite
- Leaflet
- OpenStreetMap

## 🗺️ Road Hazard Mapping
The planned mapping system will display reported hazards
on an interactive map, including their location, hazard type,
detection confidence, and reporting history.

## 📌 Project Status
Development in progress.

Individual sensors are being tested before integration into
the complete road hazard detection and mapping system.
